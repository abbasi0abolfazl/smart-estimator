# 📊 تخمینگر هوشمند (Estimator) - پلتفرم وب یادگیری ماشین

[English Documentation](README.md) • [گزارش خطا و بازخورد](https://github.com/abbasi0abolfazl/streamlit_machine_learning/issues)

یک پلتفرم وب تعاملی مهندسی‌شده با **Streamlit** و الگوریتم‌های **یادگیری ماشین (Scikit-Learn)** برای تخمین هوشمند ارزش بازار در دو حوزه کالای دیجیتال (لپ‌تاپ) و املاک (مسکن در تهران و ایران)، همراه با ماژول تحلیل اکتشافی داده‌ها (EDA).

---

## 📌 معماری و چارچوب سیستم

این پروژه فرآیند تبدیل داده‌های خام بازار به مدل‌های رگرسیونی قابل تفسیر را در سه لایه ارائه می‌دهد:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        لایه‌ی داده‌ها (Data Layer)                       │
│  - دیتاست لپ‌تاپ: سخت‌افزار، رزولوشن، وزن، پردازنده و قیمت دلاری/یورویی   │
│  - دیتاست مسکن ایران: بیش از ۱۶۰ هزار آگهی ملکی در تهران و شهرستان‌ها     │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   لایه‌ی مدل‌سازی (Modeling Engine)                     │
│  - Random Forest Regressor: تخمین ارزش سخت‌افزار با حداقل خطای واریانس   │
│  - Decision Tree Regressor: نگاشت غیرخطی ویژگی‌های مکانی و مشخصات ملک    │
│  - معیارهای ارزیابی: محاسبه برخط R² Score, MAE, MSE و خطای نسبی         │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     لایه‌ی کاربری (Interactive UI)                     │
│  - رابط کاربری Streamlit با طراحی استاندارد RTL و ناوبری چندبخشی       │
│  - ماژول تحلیل داده (EDA): ماتریس همبستگی (Heatmap) و نمودارهای توزیع │
└────────────────────────────────────────────────────────────────────────┘
```

## ✨ قابلیت‌های کلیدی

### ۱. 💻 تخمین ارزش بازار لپ‌تاپ (Laptop Valuation Engine)
- استخراج و مهندسی ویژگی‌های سخت‌افزاری: فرکانس و نوع پردازنده (CPU)، معماری گرافیک (GPU)، حافظه رم (RAM)، وزن و تراکم پیکسلی صفحه نمایش (PPI).
- پیش‌بینی بر اساس مدل گروهی **Random Forest** با دقت تعمیم بالا.
- نمایش دوگانه قیمت بر حسب **یورو (€)** و برابری ریالی/تومانی بازار.
- گزارش معیارهای ارزیابی دقت مدل ($R^2$ Score, MAE, RMSE).

### ۲. 🏠 تخمین ارزش رهن و مسکن در ایران (Real Estate Valuation Engine)
- آموزش‌دیده بر روی دادگان بیش از **۱۶۰,۰۰۰ رکورد** ملکی ثبت‌شده.
- پیش‌پردازش و نگاشت ویژگی‌های دسته‌ای با کدگذاری برچسبی محله‌ها (`LabelEncoder`).
- پارامترهای ورودی: متراژ زیربنا، سن ساختمان، طبقه، تعداد اتاق، آسانسور، پارکینگ و انباری.
- پیش‌بینی هم‌زمان ارزش خرید و رهن کامل با استفاده از رگرسیون درخت تصمیم.

### ۳. 📈 تحلیل اکتشافی داده‌ها (Data Cleaning & EDA Suite)
- مقایسه بلادرنگ داده‌های خام و دیتاست مهندسی‌شده.
- ماتریس همبستگی ویژگی‌ها به همراه نمودار هیت‌مپ حرارتی.
- امکان بارگذاری فایل‌های سفارشی اکسل (`.xlsx`) و کاما-جدا (`.csv`) توسط کاربر.

## 🛠️ نصب و راه‌اندازی

```bash
# کلون مخزن
git clone https://github.com/abbasi0abolfazl/streamlit_machine_learning.git
cd streamlit_machine_learning

# ایجاد محیط مجازی
python3 -m venv .venv
source .venv/bin/activate

# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای وب‌اپلیکیشن
streamlit run main.py
```
